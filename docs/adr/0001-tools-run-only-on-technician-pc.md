# Tools run only on the Technician's PC

Every Tool executes on the Technician's own Windows PC; there are no remote agents and no central server. This keeps v1 free of deployment, auth and backend work, at the cost that a Tool can only ever see the network from where the Technician sits — "Traceroute from the branch office" is impossible by design, not a missing feature. Remote agents are deferred to the end of the backlog.
